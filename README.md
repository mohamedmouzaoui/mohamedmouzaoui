Cybersecurity graduate and full-stack developer focused on threat detection, SOAR automation and containerized deployment. I'm looking for an entry-level SOC analyst, detection engineering or security engineering role, remote or on-site.

## Featured projects

- **Sentinel XDR Pro** — final-year capstone (with a teammate), awarded Best Startup Work at university. A six-container autonomous XDR platform: 7 Sigma rules mapped to MITRE ATT&CK, 6 SOAR playbooks, Isolation Forest and Random Forest models. 92.7% detection accuracy at 1,500 events/sec, 45 ms average latency, sub-60-second automated ransomware containment.
- **Attack Path Visualizer** — BloodHound-inspired attack-path mapping tool on a fictional corporate network ("NimbusCorp"). FastAPI + NetworkX backend, React/Vite frontend, paths traced to MITRE ATT&CK techniques.
- **PhishGuard** *(in progress)* — multi-vector phishing scanner combining VirusTotal, Google Safe Browsing and Groq. FastAPI + Docker.
- **Theft Detection AI** and **File Scanner / Malware Detector** — anomaly-driven physical security monitoring and local threat triage.
